Pencarian lirik terakhir:

Belum ada pencarian lirik.
Panduan: membuat bot Discord pribadi (sekali saja, ±5 menit)
  1. Buka discord.com/developers/applications di browser dan login.
  2. Klik New Application, beri nama (misalnya Lansky), centang persetujuan, lalu Create.
  3. Di menu kiri pilih Bot. Klik Reset Token, lalu Copy. Tempel di kolom Token bot di atas.
  4. Masih di halaman Bot, gulir ke Privileged Gateway Intents dan nyalakan Message Content Intent. Klik Save Changes.
  5. Di menu kiri pilih OAuth2 → URL Generator. Centang bot, lalu di Bot Permissions centang View Channels dan Read Message History.
  6. Salin URL di paling bawah, buka di browser, pilih server tempat kamu dan teman biasa memutar musik, lalu Authorize.
  7. Untuk ID Discord-mu: di Discord buka User Settings → Advanced, nyalakan Developer Mode. Lalu klik kanan namamu → Copy User ID.
  8. Nyalakan sakelar Discord di atas. Status akan berubah jadi Tersambung. Putar lagu lewat Jockie, liriknya muncul di island.

Bot ini hanya membaca pesan di channel yang bisa dilihatnya dan tidak mengirim apa pun. Bot hanya "online" saat Lansky Island berjalan di laptopmu.
